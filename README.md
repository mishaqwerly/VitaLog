# VitaLog Dashboard

Patient dashboard built with React, TypeScript, Vite, TanStack Query, and Chart.js.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` — start the local app
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
